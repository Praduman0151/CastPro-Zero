# Milestone 1B engineering notes

This branch introduces private IPv4 address validation, pairing enforcement, explicit Wi-Fi/Ethernet socket binding helpers, a low-latency capture service foundation, TV decoder/receiver foundation, bundled ZXing, and CameraX QR analysis.

The runtime must remain LAN-only. Build-time Gradle dependency resolution is not a runtime network feature. No analytics, cloud SDK, Firebase, ML Kit, or Play Services integration is included.

CI success is not hardware verification. 1080p60, AirFiber hotspot routing, device codec compatibility, and end-to-end casting must be verified on the OnePlus Nord 5 and TCL Android TV before Milestone 2.
